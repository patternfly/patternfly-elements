Custom Icon Sets

Call PfV6Icon.addIconSet with a string (icon set name) and a function taking the icon set name and the icon name, and returning a URL (object) to a javascript module whose default export is a lit renderable.

<pf-v6-icon set="rh" icon="boba-tea" size="lg" loading="lazy"></pf-v6-icon>
<pf-v6-icon set="rh" icon="lifecycle" size="lg" loading="lazy"></pf-v6-icon>
import { PfV6Icon } from '@patternfly/elements/pf-v6-icon/pf-v6-icon.js';
PfV6Icon.addIconSet('rh', async (set, icon) =>
  import(`./icons/${set}/${icon}.js`)
    .then(mod => mod.default));
